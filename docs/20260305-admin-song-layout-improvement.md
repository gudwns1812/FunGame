# AdminSongPage 레이아웃 개선 계획

## 1. 개요
`AdminSongPage.tsx`에서 노래 중복 확인 버튼의 위치를 조정하고, 입력 필드의 레이아웃을 최적화하여 사용자 경험(UX)을 개선함.

## 2. 주요 변경 사항
- **노래 제목 입력 필드**: '중복 확인' 버튼과의 결합을 해제하고 전체 너비(`md:col-span-2`)를 차지하도록 복구.
- **발매일 입력 필드**: '발매일' 입력 필드 옆에 '중복 확인' 버튼을 배치하여 시각적 균형을 맞춤.
- **중복 확인 결과 메시지**: 이동된 버튼 하단(발매일 입력 영역 내)으로 이동하여 문맥에 맞는 정보를 제공.
- **반응형 디자인**: `md:col-span-*` 및 `flex-wrap` 등을 활용하여 모바일과 데스크탑 환경 모두에서 깨지지 않는 레이아웃 유지.

## 3. 작업 절차
1. `frontend/src/pages/AdminSongPage.tsx` 수정:
    - 제목 섹션에서 버튼 제거 및 `input` 너비 조정.
    - 발매일 섹션을 `flex` 컨테이너로 감싸고 버튼 추가.
    - 중복 확인 결과 메시지(`duplicateStatus` 관련 코드)를 발매일 섹션으로 이동.
2. UI 스타일링 확인: Tailwind CSS 클래스를 사용하여 기존 테마(미래지향적/게임 UI) 유지.
3. 결과 검토: 레이아웃 및 기능 작동 여부 확인.
